# 🏊‍♂️ Pool Counter App

Простое и удобное приложение для подсчёта проплытых дорожек в бассейне.  
Помогает сфокусироваться на тренировке, не сбиваясь со счёта ✨

---

## 🚀 Функционал

- ➕ Увеличение счётчика  
- 🔄 Полный сброс  
- ⚡ Мгновенная работа без перезагрузки страницы

---

## 🎯 Зачем это нужно?

- Контроль количества заплывов 🏊‍♂️  
- Удобный трекинг прогресса  
- Минимум лишнего — максимум пользы
